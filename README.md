## The line

## How it works

`main.py` (stdlib only) writes that single line to `entry.txt` in
`MAKEFUN_OUTPUT_DIR` (or the script directory when unset). The sealed
scorer requires 1–180 UTF-8 characters; this line is 113 characters.
